Detailed Description

template<typename T>
class SINRICPRO_3_5_0::OpenCloseController< T >

Controller class for devices with open/close functionality

This controller handles open/close operations for devices that can be opened or closed by percentage and may supports multiple directions.

Template Parameters
TDevice type that implements this controller
