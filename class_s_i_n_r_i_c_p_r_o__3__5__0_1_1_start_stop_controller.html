Detailed Description

template<typename T>
class SINRICPRO_3_5_0::StartStopController< T >

StartStopController class to handle start/stop and pause/unpause functionality.

This template class provides functionality to control devices that can be started, stopped, paused, and unpaused (like a vacuum cleaner, washing machine, etc.)

Template Parameters
TThe device type that this controller is attached to
